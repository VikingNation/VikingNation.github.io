Deck Builder is a stand-alone application for 64-bit Windows 10 and Windows 11.

Deck Builder is a standalone tool for creating radio pack folders — themed sets of equipment artwork that players can install in the [SUPERSTATION]({{ site.baseurl }}/software/superstation) application. A pack replaces the default card art for four equipment slots (Computer, Radio, Amplifier, and Antenna) across five level tiers.

Deck Builder handles:
- Assembling and validating your image assets
- Generating the pack.json manifest with metadata and SHA-256 image hashes
- Signing the manifest with an OpenPGP key so SUPERSTATION can verify authenticity
- Verifying the integrity of your own or someone else's pack before distribution
