Around 2300 UTC on Sunday, November 8th, x0rro, the developer of XARA, shut down the project and removed all source code from the GitHub repository. XARA, the VARA-compatible HF/VHF modem for Linux, had been released only two weeks earlier and drew a lot of interest from the ham radio community. Full details are in the following YouTube video.

{% include embed/youtube.html id='ywDRTkhIuY8' %}

<a href="https://youtu.be/ywDRTkhIuY8" target="_blank" rel="noopener noreferrer">Watch on YouTube: XARA Project shuttered</a>

The [x0rro/xara GitHub repository](https://github.com/x0rro/xara){:target="_blank" rel="noopener noreferrer"} is now marked "discontinued", and its README reads:

> development and distribution of xara is discontinued effective
> immediately. sharing xara with the world proved one thing: there is
> demand for a lightweight, high-performance HF and FM modem that runs on
> open platforms. i encourage people who found xara useful to try the
> following modems:
>
> - mercury
> - openmodem
> - new modems as they come out

Subscribe to the <a href="https://www.youtube.com/@K3JSJ" target="_blank" rel="noopener noreferrer">"Ham Radio Community" YouTube channel</a> for continued coverage about the impact to the community and VARA software.
