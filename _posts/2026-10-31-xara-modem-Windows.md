On October 24, 2026, a developer released a VARA-compatible HF/VHF modem for Linux called Xara. See the [Xara Release post on Reddit](https://www.reddit.com/r/HamRadio/comments/1xecpml/xara_a_varacompatible_hfvhf_modem_for_linux/)

I used AI to create a working Windows version and have been testing it with my IC-7300 on 40 meters. I added FLRig support and a lightweight GUI to simplify configuration of the Xara.conf file. The software has been packaged as a ZIP archive so that other users can download and test it.
<br>
I am currently preparing a merge request for the Xara developer to incorporate these enhancements into the main codebase.
