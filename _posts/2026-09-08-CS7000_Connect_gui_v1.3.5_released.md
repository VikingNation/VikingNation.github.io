# 🐞 Bug Fixes

This is a **bug fix release** of the CS7000 Codeplug Converter software.

### **App Failing to Start (Fixed)**
Fixed the app failing to start on some machines with `ModuleNotFoundError: No module named ttkbootstrap`. The `ttkbootstrap` library is now bundled inside the executable.

Thanks to **Michael Ellithorp KF6OBI** for highlighting this bug.

### **Main Window Hidden After Registration (Fixed)**
Fixed registering from the first-run support popup leaving the main window hidden, which made the app appear to hang. The main window now comes back to the front after you register.

### **Missing Firmware Analog Channels (Fixed)**
Fixed the radio's built-in (firmware) analog channels being left out of the converted channels file when **Include radio default Zones & Channels** was selected together with **Digital** only. Those default analog channels are required by the default zones, so they are now always included. An information dialog explains this when it applies.

### **Stray Console Window (Removed)**
Removed the console window that opened behind the GUI.

### **Diagnostic Log File (New)**
Added a diagnostic log file in the configuration folder:

```
%APPDATA%\CS7000_convert_gui\CS7000_convert_gui.log
```

The log captures the **Debug Output** panel and any error messages. A **View → Open Log Folder** menu item was added so you can get to it quickly.

### **Documentation**
Updated the guided walkthrough and FAQ, covering writing the codeplug with the **Table** contact method and the log file location.
