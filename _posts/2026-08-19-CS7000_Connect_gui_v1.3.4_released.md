# 🚀 What's New

This is an **update** of the CS7000 Codeplug Converter software.

### **Software Registration (New)**
The application now supports software registration.

### **Automatic Update Checking (New)**
The application now checks for updates automatically, so you'll know when a new release is available.

### **Boot Image Editor (New)**
Added a Boot Image editor for creating welcome BMPs for the CS7000.

### **Table Method Contact Type Bug (Fixed)**
Fixed a bug where Table-method digital channels could be assigned the wrong Contact Type.

### **Configuration Folder Migration**
The application's configuration folder has been migrated to the **APPDATA** folder.

### **Documentation**
The guided Help walkthrough and user guide have been updated to reflect the changes above.
